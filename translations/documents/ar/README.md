# Conan Casebook

قائمة مشاهدة مركّزة للمحقق كونان: **255 حلقة، تسعة آركات، تقييمات IMDb مستمدة من مصادر فردية**. تم إنشاؤها بواسطة [SawabS](https://github.com/SawabS).

[فتح Conan Casebook](https://sawabs.github.io/DetectiveConanMainPlot/)

افتح [index.html](index.html) في متصفح، أو اقرأ [الدليل المنسق](https://sawabs.github.io/DetectiveConanMainPlot/guide.html). تظل تنزيلات Markdown متاحة.

- ابحث حسب العنوان أو رقم الحلقة الياباني الدقيق.
- قُم بالتصفية حسب الآرك، حالة المشاهدة، أو التقييم؛ ورتّب حسب تسلسل القصة أو النتيجة.
- احفظ تقدمك على جهازك، وتابع مع الحلقة التالية غير المشاهدة، وأخفِ عناوين الحلقات.
- تصدير/استيراد نسخ احتياطية بصيغة JSON. تدمج عمليات الاستيراد التقدم المحرز؛ وتتطلب إعادة التعيين تأكيدًا.
- افحص مصدر كل حلقة، ومطابقتها على IMDb، والأصوات، وتاريخ التحقق من التقييم.
- بدّل بين المظهر الفاتح الأزرق والداكن باستخدام زر الشمس/القمر. يتم حفظ اختيارك؛ وتتبع الزيارة الأولى مظهر نظامك.
- استكشف **خريطة القصة**: حدد آركًا أو حلقة، واسحب باستخدام الماوس أو القلم، وقُم بالتكبير/التصغير بالأزرار، أو استخدم Ctrl/Command + عجلة التمرير. يمكن لمستخدمي اللمس تحديد الآركات، والبحث عن حلقة، واستخدام عناصر التحكم في التكبير/التصغير مع الاحتفاظ بالتمرير الطبيعي للصفحة.
- تنقّل بين عُقد المخطط باستخدام مفاتيح الأسهم، وحدد بـ Enter/Space، وكبّر/صغّر بـ +/−، وأعد التعيين بـ Home. تميّز الألوان الآركات؛ وتحدد علامات الاختيار الحلقات المشاهدة. يعكس حجم العقدة تقييم IMDb للحلقة. تشير الروابط المتقطعة إلى ترتيب مشاهدة الآرك، وليس إلى علاقات حبكة مستنتجة.
- تنثني الشبكة الزرقاء الباهتة موضعيًا حول المؤشر باستجابة ناعمة ومؤجلة. يتفعّل التأثير تلقائيًا للمؤشرات الدقيقة، ويحترم إعدادات تقليل الحركة، ويتوقف عند الخمول أو عند إخفاء الصفحة.

## الأفلام

افتح **الأفلام** في شريط التنقل أو قم بزيارة [مكتبة الأفلام](https://sawabs.github.io/DetectiveConanMainPlot/#movies). وهي تغطي 29 فيلمًا رئيسيًا تم إصداره، وعملاً سينمائيًا مشتركًا واحدًا، وثلاثة أعمال تجميعية، وفيلمين قصيرين بتقنية 3D، تم فحصها في 7 September 2026. ابحث حسب العنوان، أو رقم الفيلم، أو السنة؛ وصنّف حسب الفئة وحالة المشاهدة؛ ورتّب حسب تاريخ الإصدار. يتمتع تقدم مشاهدة الأفلام بمساحة تخزين محلية خاصة به وعناصر تحكم في الاستيراد/التصدير.

يتم إنشاء [قائمة التحقق من الأفلام](detective_conan_movies.md) وكتالوج المتصفح من [data/movies.json](data/movies.json)، مع مصادر فردية وإسنادات للأعمال الفنية. يتم تحميل الأغلفة الخارجية عند الطلب وتحتفظ ببديل نصي قابل للقراءة في حال عدم توفرها.

## التحليلات

افتح [التحليلات](https://sawabs.github.io/DetectiveConanMainPlot/#analytics) لاستكشاف جميع حلقات القصة الرئيسية المميزة البالغ عددها **255 حلقة** و**35 فيلمًا**:

- حدد شريط تقييم أو مدة فردية لفحص مصادره وعدد الأصوات.
- قارن بين وسيطات الآركات، وتوزيعات التقييمات، والإصدارات اليابانية حسب السنة.
- قُم بالتصفية حسب الآرك/الفئة، وسنة الإصدار، والتقدم، ونطاق التقييم، والحد الأدنى للأصوات.
- خطط لوقت المشاهدة المتبقي باستخدام تقدمك المحفوظ وميزانية وقت يومية.
- أخفِ العناوين، وتنقّل في المخططات البيانية باستخدام لوحة المفاتيح، أو صدّر الصفوف المصفاة كملف CSV.

تحتوي جميع الحلقات البالغ عددها 255 حلقة و33 فيلمًا على تقييمات IMDb. لا يوجد للفيلمين القصيرين أي تطابق مؤكد على IMDb. تمثل مدة الحلقات **قوائم بث TVmaze**، والتي قد تتضمن إعلانات تجارية. وهي مخصصة للمساعدة في التخطيط، وليست ادعاءات دقيقة لوقت البث المباشر. انظر [المنهجية وتغطية البيانات](data/analytics-methodology.md).

## التشغيل

قُم بتنزيل المستودع وافتح `index.html`. لا يتطلب الأمر أي تثبيت أو خادم. يتم تجميع الأعمال الفنية وبيانات الحلقات معًا؛ وتعتمد خطوط الويب على خطوط النظام في وضع عدم الاتصال. تتطلب روابط المصادر اتصالاً بالإنترنت.

للحصول على أصل محلي مستقر، شغّل `python3 -m http.server 8000` وافتح `http://localhost:8000`. يتم حفظ التقدم محليًا في المتصفح؛ ولا يؤدي تبديل المتصفحات أو الأصول أو الأجهزة إلى نقله. قُم بتصدير نسخة احتياطية قبل نقل بيانات المتصفح أو مسحها.

## الصيانة

يُعد `data/episodes.json` هو المصدر الموثوق الوحيد. فهو يحتوي على الاختيارات التي تمت مراجعتها، والعناوين اليابانية، والتواريخ الأصلية، وعناوين URL للمصادر، ومعرّفات IMDb، والعناوين المترجمة، وملاحظات المطابقة، والنتائج، والأصوات، وتواريخ التحقق.

```sh
python3 -m pip install -r scripts/requirements-build.txt # Build-time Markdown renderer
python3 scripts/build.py          # Generate Markdown and browser data
python3 scripts/build.py --check  # Detect stale generated files
python3 -m unittest discover -s tests -p 'test_*.py' # Check rendered guides and links
node --test tests/analytics.test.js # Check analytics calculations and source coverage
node --test tests/core.test.js    # Check filtering, progress, and data integrity
node --test tests/graph.test.js   # Check graph coverage, camera bounds, and theme fallback
node --test tests/grid.test.js    # Check local deformation bounds and return to rest
node --test tests/movies.test.js  # Check film coverage, filtering, and movie backups
python3 scripts/refresh_ratings.py # Download updated scores for the same IDs
```

راجع مطابقات الحلقات الجديدة حسب العنوان، وسنة البث، والجزء. لا تستنتج أبدًا معرّفات IMDb من الترقيم الياباني ولا تُعد استخدام تقييم واحد عبر قضية بأكملها. يحدّث سكريبت التحديث نتائج الحلقات والأفلام، والأصوات، وتواريخ التحقق دون تغيير المعرّفات التي تمت مراجعتها. انظر [CHANGELOG](CHANGELOG.md) للاطلاع على التصحيحات الأولية.

تستخدم واجهة المستخدم تقنيات HTML وCSS وSVG وPointer Events الأصلية بدون إطار عمل للواجهة الأمامية. تغطي لوحة الألوان المشتركة الجداول، وعناصر التحكم، ومربعات الحوار، والتنقل، والمخطط البياني في كلا المظهرين. مراجع التنفيذ: [تفضيلات المظهر في MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-color-scheme)، و[تصفية الخلفية](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)، و[Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events). استند التوجيه البصري إلى [مهارة تصميم الواجهات الأمامية](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md).

## اللغات

تفتح أيقونة الكرة الأرضية بجوار عنصر التحكم في المظهر خيارات اللغات: الإنجليزية، والسورانية، والعربية، واليابانية. اللغات الثلاث الجديدة هي **معاينات ترجمة**، مع تسميات تنقل والرجوع للغة الإنجليزية كبديل حتى يُكمل الوكيل المراجعة. تستخدم السورانية والعربية اتجاه الكتابة من اليمين إلى اليسار (RTL) وخط IBM Plex Sans Arabic المضمّن؛ وتستخدم اليابانية IBM Plex Sans JP مع خطوط نظام بديلة. يتم حفظ تفضيلات اللغة بشكل منفصل عن تقدم المشاهدة.

زوّد وكيل الترجمة الخاص بك بملف [translations/AGENT_PROMPT.md](translations/AGENT_PROMPT.md). يحتوي [دليل الترجمة](translations/README.md) على كتالوجات قابلة للتعديل وقوائم حصر كاملة لنصوص الواجهة، وسلاسل JavaScript النصية الديناميكية، ومحتوى الحلقات/الأفلام، ومستندات المصدر. قُم بتجميع الترجمات المكتملة باستخدام `python3 scripts/translations.py`.
