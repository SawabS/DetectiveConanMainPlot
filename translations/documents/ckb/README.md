# Conan Casebook

لیستێکی سەرنجخراوی سەیرکردنی لێکۆڵەر کۆنان: **255 ئەڵقە، نۆ ئارک، هەڵسەنگاندنەکانی IMDb کە سەرچاوەیان بە تاک دیاری کراوە**. دروستکراوە لەلایەن [SawabS](https://github.com/SawabS).

[کردنەوەی Conan Casebook](https://sawabs.github.io/DetectiveConanMainPlot/)

پەڕگەی [index.html](index.html) لە وێبگەڕێکدا بکەرەوە، یان [ڕێنمای شێوازدار](https://sawabs.github.io/DetectiveConanMainPlot/guide.html) بخوێنەرەوە. داگرتنەکانی Markdown بەردەست دەمێننەوە.

- گەڕان بەپێی ناونیشان یان ژمارەی دروستی ئەڵقەی ژاپۆنی.
- پاڵاوتن بەپێی ئارک، دۆخی بینین، یان هەڵسەنگاندن؛ ڕیزکردن بەپێی ڕیزبەندی چیرۆک یان نمرە.
- پاشەکەوتکردنی بەرەوپێشچوون لەسەر ئامێرەکەت، بەردەوامبوون لەگەڵ ئەڵقەی نەبینراوی دواتر، و شاردنەوەی ناونیشانی ئەڵقەکان.
- هەناردن/هاوردەکردنی پاڵپشتی JSON. هاوردەکردن پێشکەوتنەکان تێکەڵ دەکات؛ دووبارە ڕێکخستنەوە پێویستی بە دووپاتکردنەوەیە.
- پشکنینی سەرچاوەی هەر ئەڵقەیەک، نەخشاندنی IMDb، دەنگەکان، و ڕێکەوتی پشکنینی هەڵسەنگاندن.
- گۆڕین لەنێوان ڕووکەشی ڕووناکی شین و تاریک بە دوگمەی خۆر/مانگ. هەڵبژاردنەکەت پاشەکەوت دەکرێت؛ یەکەم سەردان پەیڕەوی ڕووکەشی سیستەمەکەت دەکات.
- گەڕان لە **نەخشەی چیرۆک**: ئارکێک یان ئەڵقەیەک هەڵبژێرە، بە ماوس یان پێنووس ڕابکێشە، بە دوگمەکان زووم بکە، یان Ctrl/Command + ویل بەکاربهێنە. بەکارهێنەرانی دەستلێدان دەتوانن ئارکەکان هەڵبژێرن، بۆ ئەڵقەیەک بگەڕێن، و کۆنتڕۆڵەکانی زووم بەکاربهێنن لەکاتێکدا جووڵاندنی ئاسایی پەڕەکە دەپارێزرێت.
- بە کلیلەکانی تیر لەنێوان گرێکانی هێڵکاریدا هاتووچۆ بکە، بە Enter/Space هەڵیبژێرە، بە +/− زووم بکە، و بە Home بیگەڕێنەرەوە دۆخی سەرەتا. ڕەنگەکان ئارکەکان دیاری دەکەن؛ نیشانەکانی پشکنین (check mark) ئەڵقە بینراوەکان دیاری دەکەن. قەبارەی گرێکان گوزارشت لە هەڵسەنگاندنی IMDbی ئەڵقەکە دەکات. بەستەرە پچڕپچڕەکان ئاماژەن بۆ ڕیزبەندی سەیرکردنی ئارک، نەک پەیوەندییە خەمڵێنراوەکانی پڵۆت.
- تۆڕە شینە کاڵەکە بە شێوەیەکی ناوخۆیی لە دەوری نیشاندەرەکە بە وەڵامدانەوەیەکی نەرم و دواکەوتوو دەچەمێتەوە. کاریگەرییەکە خۆکارانە بۆ نیشاندەرە وردەکان کارا دەبێت، ڕێز لە ڕێکخستنەکانی کەمکردنەوەی جووڵە دەگرێت، و لەکاتی بێجووڵەیی یان شاردنەوەی پەڕەکەدا دەوەستێت.

## فیلمەکان

لە شریتی ڕێدۆزیدا بەشی **فیلمەکان** بکەرەوە یان سەردانی [کتێبخانەی فیلمەکان](https://sawabs.github.io/DetectiveConanMainPlot/#movies) بکە. ئەم بەشە 29 فیلمی سەرەکی بڵاوکراوە، یەک فیلمی هاوبەشی سینەمایی، سێ کۆکراوە، و دوو کورتەفیلمی 3D لەخۆدەگرێت، کە لە 7 September 2026 پشکنراون. گەڕان بەپێی ناونیشان، ژمارەی فیلم، یان ساڵ؛ پاڵاوتن بەپێی پۆلێن و دۆخی سەیرکردن؛ ڕیزکردن بەپێی ڕێکەوتی بڵاوبوونەوە. بەرەوپێشچوونی فیلمەکان کۆگای ناوخۆیی و کۆنتڕۆڵەکانی هاوردەکردن/هەناردەکردنی تایبەت بە خۆی هەیە.

[پێڕستی فیلمەکان](detective_conan_movies.md) و کەتەلۆگی وێبگەڕ لە [data/movies.json](data/movies.json) بەرهەمهێنراون، لەگەڵ سەرچاوە سەربەخۆکان و مافی بەرگە هونەرییەکان. بەرگە دەرەکییەکان بەپێی پێویست باردەکرێن و لەکاتی نەبووندا جێگرەوەیەکی خوێنراوە دەپارێزن.

## شیکاری

بەشی [شیکاری](https://sawabs.github.io/DetectiveConanMainPlot/#analytics) بکەرەوە بۆ گەڕان لە هەموو **255 ئەڵقەی جیاوازی چیرۆکی سەرەکی** و **35 فیلم**:

- ستوونێکی دیاریکراوی هەڵسەنگاندن یان ماوە هەڵبژێرە بۆ پشکنینی سەرچاوەکان و ژمارەی دەنگەکانی.
- بەراوردکردنی ناوەڕاستە (median)کانی ئارک، دابەشبوونی هەڵسەنگاندنەکان، و بڵاوکراوە ژاپۆنییەکان بەپێی ساڵ.
- پاڵاوتن بەپێی ئارک/پۆلێن، ساڵی بڵاوبوونەوە، بەرەوپێشچوون، مەودای هەڵسەنگاندن، و کەمترین ژمارەی دەنگەکان.
- پلاندانان بۆ کاتی سەیرکردنی ماوە لە ڕێگەی بەرەوپێشچوونی پاشەکەوتکراوت و دیاریکردنی کاتی ڕۆژانە.
- شاردنەوەی ناونیشانەکان، گەڕان لە هێڵکارییەکان بە کیبۆرد، یان هەناردەکردنی ڕیزە پاڵێوراوەکان وەک CSV.

هەموو 255 ئەڵقەکە و 33 فیلم خاوەنی نمرەی IMDbن. دوو کورتەفیلمەکە هیچ هاوتایەکی پشتڕاستکراوەی IMDbیان نییە. ماوەی ئەڵقەکان بریتییە لە **پێڕستی پەخشی TVmaze**، کە ڕەنگە ڕیکلامیش لەخۆبگرێت. ئەمانە بۆ یارمەتیدانی پلاندانانن، نەک بانگەشەی کاتی تەواوی پەخشکردنی ڕاستەوخۆ. بڕوانە [میتۆدۆلۆژیا و رووماڵکردنی دراوەکان](data/analytics-methodology.md).

## کارپێکردن

کۆگاکە دابگرە و `index.html` بکەرەوە. هیچ دامەزراندنێک یان ڕاژەکارێک پێویست نییە. بەرهەمە هونەرییەکان و دراوەی ئەڵقەکان بەیەکەوە پێچراونەتەوە؛ فۆنتەکانی وێب لە دۆخی دەرەوەی هێڵدا دەگەڕێنەوە سەر فۆنتەکانی سیستەم. بەستەری سەرچاوەکان پێویستیان بە هێڵی ئینتەرنێت هەیە.

بۆ سەرچاوەیەکی ناوخۆیی جێگیر، فەرمانی `python3 -m http.server 8000` جێبەجێ بکە و `http://localhost:8000` بکەرەوە. بەرەوپێشچوون تەنها لەناو وێبگەڕدا پاشەکەوت دەبێت؛ گۆڕینی وێبگەڕ، سەرچاوە، یان ئامێر نایگوازێتەوە. پێش گواستنەوە یان سڕینەوەی دراوەکانی وێبگەڕ، پاڵپشتییەک هەناردە بکە.

## چاکسازی و پاراستن

پەڕگەی `data/episodes.json` سەرچاوەی بنەڕەتییە. هەڵبژاردنە پێداچوونەوەپێکراوەکان، ناونیشانە ژاپۆنییەکان، ڕێکەوتە بنەڕەتییەکان، بەستەری سەرچاوەکان، ناسێنەری IMDb، ناونیشانە وەرگێڕدراوەکان، تێبینییەکانی نەخشاندن، نمرەکان، دەنگەکان، و ڕێکەوتەکانی پشکنین لەخۆدەگرێت.

```sh
python3 -m pip install -r scripts/requirements-build.txt # Build-time Markdown renderer
python3 scripts/build.py          # Generate Markdown and browser data
python3 scripts/build.py --check  # Detect stale generated files
python3 -m unittest discover -s tests -p 'test_*.py' # Check rendered guides and links
node --test tests/analytics.test.js # Check analytics calculations and source coverage
node --test tests/core.test.js    # Check filtering, progress, and data integrity
node --test tests/graph.test.js   # Check graph coverage, camera bounds, and theme fallback
node --test tests/grid.test.js    # Check local deformation bounds and return to rest
node --test tests/movies.test.js  # Check film coverage, filtering, and movie backups
python3 scripts/refresh_ratings.py # Download updated scores for the same IDs
```

پێداچوونەوە بە نەخشاندنی ئەڵقە نوێیەکاندا بکە بەپێی ناونیشان، ساڵی پەخش، و بەش. هەرگیز ناسێنەری IMDb لە ژمارەدانانی ژاپۆنییەوە مەخەمڵێنە و نمرە بەسەر تەواوی کەیسێکدا دووبارە بەکارمەهێنەرەوە. سکریپتی نوێکردنەوە نمرەکانی ئەڵقە و فیلم، دەنگەکان، و ڕێکەوتەکانی پشکنین نوێ دەکاتەوە بەبێ گۆڕینی ناسێنەرە پێداچوونەوەپێکراوەکان. بڕوانە [CHANGELOG](CHANGELOG.md) بۆ ڕاستکردنەوە سەرەتاییەکان.

ڕووکاری بەکارهێنەر HTML، CSS، SVG، و Pointer Eventsی ڕەسەن بەکاردەهێنێت بەبێ فرەیموۆرکێکی پێشەوە (front-end). پالتە ڕەنگییە هاوبەشەکە خشتەکان، کۆنتڕۆڵەکان، دیالۆگەکان، ڕێدۆزی، و هێڵکارییەکە لە هەردوو ڕووکەشدا دەگرێتەوە. سەرچاوەکانی جێبەجێکردن: [هەڵبژاردەکانی ڕووکەشی MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-color-scheme)، [پاڵاوتنی پاشبنەما](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)، و [Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events). ئاڕاستەی بینراو بە سوودوەرگرتن لە [شارەزایی دیزاینی Frontend](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md) بووە.

## زمانەکان

گۆی زەوی تەنیشت کۆنتڕۆڵی ڕووکەش هەڵبژاردنەکانی زمانی ئینگلیزی، سۆرانی، عەرەبی، و ژاپۆنی دەکاتەوە. سێ زمانە نوێیەکە **پێشبینینی وەرگێڕان**ن، لەگەڵ ناونیشانەکانی ڕێدۆزی و گەڕانەوە بۆ ئینگلیزی هەتا ئەوکاتەی بریکارەکە پێداچوونەوە تەواو دەکات. سۆرانی و عەرەبی ئاڕاستەی ڕاست-بۆ-چەپ (RTL) و فۆنتی ناوخۆیی IBM Plex Sans Arabic بەکاردەهێنن؛ ژاپۆنی IBM Plex Sans JP لەگەڵ فۆنتە جێگرەوەکانی سیستەم بەکاردەهێنێت. هەڵبژاردنی زمان بە جیا لە بەرەوپێشچوونی سەیرکردن پاشەکەوت دەکرێت.

[بوخچەی وەرگێڕان](translations/README.md) کەتەلۆگە دەستکاریکراوەکان و پێڕستی تەواوی دەقەکانی ڕووکار، دەقە داینامیکییەکانی JavaScript، ناوەڕۆکی ئەڵقە/فیلم، و بەڵگەنامەکانی سەرچاوە لەخۆدەگرێت. وەرگێڕانە تەواوکراوەکان بە `python3 scripts/translations.py` کۆمپایل بکە.
